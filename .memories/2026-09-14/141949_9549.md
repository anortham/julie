## Windows search-matrix TOML fixture fixed

### WHAT

Updated `xtask-eval/tests/search_matrix_contract_tests.rs` so `search_matrix_contract_tests_baseline_no_longer_errors_on_removed_workspace_pool` serializes its temporary Windows root with the existing `toml_roots` helper.

### WHY

The Windows full gate failed because direct `format!` interpolation emitted paths such as `C:\\Users\\...` into TOML, where `\\U` was parsed as an invalid Unicode escape. The sibling escaping contract already covered the correct serializer.

### HOW

Kept the baseline assertions and runner unchanged; replaced the hand-built `roots = ["{}"]` fragment with `toml_roots(&[roots_dir.to_string_lossy().into_owned()])`, then embedded the serialized roots block in the corpus fixture.

### IMPACT

The exact package test passed 1/1 on Windows. `git diff --check` is clean. No production code changed; the working tree remains shared and intentionally dirty with the parent Windows-release fixes.
