## WHAT

Julie v8.0.0 and its plugin distribution are publicly released and verified. The Julie tag `v8.0.0` points to `1eb4977eeee9e1bfced5317cc268bd8676fed254`; the public release is https://github.com/anortham/julie/releases/tag/v8.0.0. Corrected plugin source commit `d427fec9df777b045d4562a4e56e3f14f0a7a260` is preserved by tag `v8.0.0-source.1`; successful workflow run `34864907371` published plugin main `a51922279f4191f26facdb67fc5c676e4ebd9c49`.

## WHY

The initial release pipeline built all archives but its public verifier rejected the valid Windows GNU checksum marker. After that verifier was fixed, two plugin workflow contract defects were found and repaired: manual dispatch lacked a token fallback, and validation required nonexistent `mcp_codex.json` instead of the designed `mcp.json` plus `mcp_config.json` pair.

## HOW

Used TDD for each local correction, with observed RED and GREEN exact tests. Windows `cargo xtask test full` passed all 5/5 commands (2,291 dev tests, 69 dogfood tests). Release workflow `34859615247` successfully built/verified the four platform archives before the known verifier false negative. Downloaded all public assets, independently checked hashes, and confirmed release notes exactly match `docs/release-notes/v8.0.0.md`. The corrected plugin workflow passed; a fresh public clone confirmed all six manifests at 8.0.0, required files non-empty, no `mcp_codex.json`, no symlinks/extracted target directories, and byte-for-byte archive hash parity.

## IMPACT

Users can download Julie v8.0.0 for Windows, Linux, Intel macOS, and Apple Silicon, and the plugin distribution now serves v8.0.0. Future releases use the corrected checksum parser and plugin source pin. The original failed release run remains historical evidence; no released tag or archive was rewritten because the release bytes were valid.
