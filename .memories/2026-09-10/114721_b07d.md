## Task 1: `julie-facts` crate — schema, store, writer, reader, version

**WHAT**
- New crate `crates/julie-facts` (blob-keyed `facts.sqlite`): `schema.rs` (14 tables + indexes, `meta`), `store.rs` (`FactsStore::open` → `Opened::{Ready, VersionMismatch}`, `in_memory`), `writer.rs` + `insert.rs` (`FactsWriter::apply`, `Extractor` trait, `PathChange`, `Applied`), `reader.rs` (`FactsReader` per-path queries), `rows/` (row structs, `Normalization`, ported test-role classifier, type-argument flattening), `version.rs` (`FACTS_SCHEMA_VERSION = 1`, new `SEMANTIC_INDEX_ENGINE_VERSION = extractors=<contract>+extractors-tag=v2.42.0+facts=1`).
- `src/tools/workspace/indexing/engine_version.rs` now re-exports the version from `julie_facts`; `SEMANTIC_INDEX_ENGINE_COMPONENT` kept (10 callers).
- xtask bucket `core-facts` in nano/fast/smoke/dev/full.

**WHY**
Phase 3 replaces path-keyed `symbols.db` with immutable blob-keyed facts. Task 2 (graph) and Task 3 (snapshot) build on this crate.

**HOW**
- Extractor ids become per-blob ordinals; `parent_id`/`containing_symbol_id`/`from_symbol_id` map to ordinals, out-of-blob targets become name-only.
- Only `UPDATE paths` / `DELETE FROM paths` in the writer (test scans the source).
- Literal classification reuses `julie_extractors::classify_literals_by_carrier` (the extractor crate owns carrier policy); test roles are injected via `Normalization.test_roles`.
- `expected_seconds = 2` for `core-facts` (plan said 5): dev tier was at 598s and the manifest rejects >600s.
