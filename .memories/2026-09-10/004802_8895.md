## Task 6: deleted the Python embedding host; tests default to no embeddings

**WHAT**
- Deleted the `uv`-provisioned Python sidecar (`python/embeddings_sidecar/`), its Rust bootstrap/supervisor/embedded-source/host-server/host-transport/rpc-client modules, the `julie-embedding-host` binary, `src/embedding_host_launch.rs`, the registry `EmbeddingService`, `RegistryPaths::embedding_host_*`, the `embeddings-sidecar` cargo feature, the `include_dir` dependency, the sidecar benchmark script, and `docs/operations/embedding-sidecar.md`.
- `EmbeddingBackend` has no `Sidecar` variant. `parse_provider_preference` accepts `auto|native` (`none` is handled before parsing); `sidecar`/`ort` return a removal error. `BackendResolverCapabilities::detect(native_program)` probes for the `julie-semantic-sidecar` binary; `auto` resolves to `Native` when found, else no provider.
- `acquire_in_process_embedding_provider()` no longer takes `RegistryPaths`; it runs `create_embedding_provider()` off-thread.
- `JulieServerHandler` lost the `embedding_service` field and the daemon-only branches (deferred daemon embedding, `EmbeddingOutcome.deferred`, dashboard service wiring, health `service_configured/settling` params).
- `.cargo/config.toml` `[env]` sets `JULIE_EMBEDDING_PROVIDER = "none"` for every cargo test binary; per-test `none` settings removed.
- Test process leak fixed: `KillOnDrop(Child)` guard in `native_provider_challenges.rs` (shared by the replacement challenge) and in `native_semantic_lifecycle.rs`; mock brokers launched by the product (`--lock` arg) now exit on stdin EOF like the real broker.

**WHY** Phase 2 of the machine-service design: one process, native semantics only, no shared host, tests must never spawn embedding processes by default. Evidence: ~50 stale `mock-broker-bin` processes after `cargo xtask test dev`.

**HOW** TDD: `test_create_embedding_provider_defaults_to_no_provider_without_test_override` red without the `[env]` line, green with it; `kill_on_drop_reaps_child_when_guard_drops` red with a no-op drop, green with kill+wait.
