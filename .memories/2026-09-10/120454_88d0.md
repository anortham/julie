## Task 2: in-memory graph and name resolution over facts rows

**WHAT**
- New `crates/julie-index/src/graph/` (`mod`, `load`, `resolve`, `edges`, `web_edges`, `scores`) plus tests under `src/tests/graph/`.
- `Graph::load(reader, paths)` reads rows per path through `FactsReader`, resolves once, computes reference scores, records `load_millis` and estimated `resident_bytes`.
- `Graph::apply_paths(reader, changed, removed)` shares unchanged per-file `Arc<[Row]>` arrays and re-reads only changed paths.
- Dense `SymbolId(u32)` in path order then ordinal order; CSR adjacency in both directions; `callers/callees/references_to/references_from/children/parent/implementations`.

**WHY**
- Phase 3 replaces SQL walks over `symbols.db` with an in-memory graph that Task 3 wraps in a snapshot.

**HOW (rules kept)**
- Identifier kinds: call -> Calls, type_usage -> References; other kinds skipped (extractor has no `import` identifier kind).
- Exact name, then `Parent::leaf` / `Parent.leaf` suffix with parent preference; same-file definitions win; definition priority (class/interface > function > method > type > variable); a tie drops the edge.
- Import/Export symbols are never resolution targets; self edges dropped.
- Relationship kinds: Instantiates -> Calls, Overrides -> Implements, other soft kinds -> References.
- Web edges: same verb/template/confidence/ambiguity rules as the pipeline `web_edges.rs`, one `WebRoute` edge per matched client call.
- Scores: weights Calls 3 / Implements+Imports+Extends 2 / References 1 / Contains+WebRoute 0, then interface->implementation 70%, constructor->class 70%, test-path x0.1 (`is_test_path`), C header->implementation 70%.

**IMPACT**
- 30 graph tests green (`cargo nextest run -p julie-index --lib tests::graph`); seed fixture loads under 2s with real extractor.
- Finding: the Rust extractor emits `lib::f()` path calls as `VariableRef` identifiers, so no Calls edge for Rust seed files; Python seed gives the Calls edge.
- Incremental re-resolves all edges in memory (row re-read is the saving); a per-file edge cache is the upgrade path if resolution cost shows up.
