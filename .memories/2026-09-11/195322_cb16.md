## Incident: test runs leaked one service process per parity or scenario test

**WHAT**: `src/tests/request_process_helpers.rs` now sets `JULIE_SERVICE_IDLE_SECS=2` in the child environment at both spawn sites (stdio MCP child and CLI child). The detached service each test's shim starts exits two seconds after its last request.

**WHY**: The service's default idle timeout is 30 minutes. The fixture killed only the stdio shim on shutdown and drop, so every parity and scenario test left a 64 MB service behind. Seven gate runs left 129 of them, 8.2 GB.

**HOW**: Grouped the leaked processes by NEXTEST_TEST_NAME from /proc environ, read the idle config in `src/service/mod.rs`, chose the env var over a `service stop` call in Drop because Drop is sync and the env var is two lines.

**IMPACT**: Whole-workspace runs no longer accumulate services. The leak only became visible because the branch runs the 319 previously uncovered tests. Killed the 129 stale processes by anchored pkill.
