## Task 2 landed: re-export index and opt-level 1 for julie-index

**WHAT**: `ReexportIndex` in `crates/julie-index/src/graph/reexports.rs`, built once per `resolve` and passed through `resolve_target` to `resolve_reexport`, `direct_targets`, `glob_targets`. `Cargo.toml` gains `[profile.dev.package.julie-index] opt-level = 1`. Two new tests under `crates/julie-index/src/tests/graph/reexports.rs`.

**WHY**: Each unresolved `crate::` reference rebuilt the import list over 76,541 symbols and recomputed `module_path` per import. This was 8.3 s of every dogfood test's store open, and the live service pays it on every store open too.

**HOW**: Precompute `(SymbolId, module_path)` for the 4,201 imports once. Measured on `test_stemming_estimation_finds_estimator`: baseline 8.4 to 9.7 s; index alone 3.1 s; index plus profile 1.4 s (6x).

**IMPACT**: Dogfood tier should drop from 81 s to about 15 s for the test part. Service `graph_load_millis` should drop in release too (report-only measurement in Task 6).
