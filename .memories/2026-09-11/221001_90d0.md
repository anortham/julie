## Task 7: harness checks done; Codex and Antigravity need a user-level MCP entry

- **WHAT:** All six harness checks pass with the 8.0.0 service. Claude Code (`--plugin-dir`, tool `mcp__plugin_julie_julie__fast_search`), OpenCode (global `opencode.json`, `julie_fast_search`), Hermes (`hermes mcp add`, 10 tools), Cursor (`~/.cursor/mcp.json`, `cursor-agent mcp list-tools julie` 10 tools, `cursor-agent -p --force`), Codex (config-level `[mcp_servers.julie]`), Antigravity (`~/.gemini/config/mcp_config.json` entry). Each returned `:52 find_default_sidecar_binary function`.
- **WHY the design changed:** Codex and Antigravity start a plugin's MCP servers with cwd = plugin directory, send no MCP roots, and pass no project path. The v8 shim binds tool calls to its cwd, so the plugin-declared server indexed the plugin directory and answered "No results". The design doc's "Agent Plugins mcp.json" and "mcp_config.json" rows assumed the harness starts servers in the project; that assumption is false.
- **HOW:** julie: `src/service/shim.rs` gains `shim_workspace_root()` (`JULIE_WORKSPACE`, else cwd, via `resolve_workspace_startup_hint`) and `run_stdio_shim` uses it; the README promised this env var and the shim ignored it. README Codex and Antigravity sections now show the config entry; the client roots table is replaced by one workspace-resolution paragraph. Plugin (commit pending): `mcp.json` and `mcp_config.json` deleted, `.codex-plugin/plugin.json` loses `mcpServers`, README and CLAUDE.md updated.
- **Other findings:** `codex exec` refuses MCP tool calls unless `--approve-for-me` or a `default_tools_approval_mode` config; `cursor-agent -p` needs `--force` for tool calls; Antigravity ignores `hooks/hooks.json` (expects root `hooks.json`); `agy -p` first ran with "You are not logged into Antigravity" in the log, later runs completed; `hermes mcp add` rewrites `config.yaml` key order, so restore by copying the backup; `codex exec` from a new directory adds a `[projects."<dir>"] trust_level` entry to `~/.codex/config.toml`.
- **Environment:** Codex, Hermes, Antigravity, Cursor configs restored byte for byte against the backups; OpenCode `opencode.json` deleted and `install-opencode.cjs --uninstall` run; Codex and Antigravity plugin installs removed; junk workspaces `7_18_0_4ec09a6a` and `julie_69be6685` removed from the service.
- **IMPACT:** Next: commit plugin changes, `cargo xtask test full` at the julie code HEAD (src changed), finding, ledger, brief, finishing-a-development-branch.
