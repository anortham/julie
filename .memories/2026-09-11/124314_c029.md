## CLI test bucket pollutes the live registry

**WHAT:** `~/.julie/registry.db` holds 231 workspace rows under `/tmp/` created 2026-09-10 to 2026-09-11. Names match the `cli` bucket fixtures: `julie_cli_definition_search_*`, `julie_cli_workspace_status_*`, `julie_cli_workspace_rebuild_*`, and `.tmp*` dirs. The live service lists every one as a checkout with `root_exists: false`.

**WHY it matters:** Every service start loads 232 dead checkouts. This likely inflates the 3.3 GB resident memory number from the 6a gate and makes `service status` unreadable.

**HOW found:** `service status` while checking Task 2 preconditions for the hybrid auto backend plan.

**IMPACT:** The CLI tests spawn the real binary without an isolated `JULIE_HOME`. Fix belongs to cleanup item 3 in the brief: set a temp `JULIE_HOME` in the CLI test harness, and add a registry prune for roots that no longer exist.
