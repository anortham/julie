## Portable release-version extraction ready

### WHAT

Both native qualification and release workflows now extract the root Cargo package version with portable `awk` instead of a GNU-only sed address.

### WHY

BSD sed on GitHub's macOS runner does not support the `0,/pattern/` range. It returned an empty version, creating `julie-v-aarch64-apple-darwin.tar.gz`; archive verification correctly rejected the packaged 8.0.0 server against the empty expected version.

### HOW

Repository search found exactly two affected workflow commands. A focused host-executed test was added first, then both commands were replaced with the same `awk -F '"'` expression. The test verifies the actual extracted Cargo version and forbids the GNU-only sed form in both workflows.

### IMPACT

The macOS packaging path can carry the correct version. The current hosted run remains untouched so remaining Windows/Intel failures can be classified before requesting the required additional qualification run.
