## Native offline probe now sends the real CLI policy

### WHAT

The probe constructs the packaged search command with top-level `--semantics required` before `tool` and also keeps the tool parameter. Its success predicate now requires a semantic backend and rejects fallback.

### WHY

Run `34760490971` showed the command exiting successfully while the response reported `mode=auto` and used lexical fallback. The probe was not exercising the CLI request-policy path it intended to qualify.

### HOW

The exact `--self-test` first rejected the old command shape, then passed after adding `search_command`. The response contract now checks outer required/ready/full readiness, `structuredContent.backend=semantic`, `trace.backend_fallback=false`, and the expected symbol.

### IMPACT

Future native qualification cannot pass on lexical fallback or an auto-mode request. This is a local fix only; no additional hosted run is authorized.
