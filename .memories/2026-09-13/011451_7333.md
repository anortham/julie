## Fixed the packaged-service cleanup race

- **WHAT:** Made release archive verification wait for `service.json` removal after a successful packaged `service stop` instead of checking immediately.
- **WHY:** Real Linux package qualification showed that stop can return just before asynchronous discovery-record cleanup, producing a false release failure even though the process and record disappear normally.
- **HOW:** Added a fresh-stat condition loop using a monotonic one-second deadline and 20 ms polling. The exact archive-qualification test now covers delayed cleanup as a pass and a never-removed record as a failure.
- **IMPACT:** Healthy packaged shutdown no longer races the verifier, while stuck cleanup and nonzero stop still fail qualification.
