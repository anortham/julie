## Native semantic qualification now uses the persistent service

### WHAT

The cached/offline semantic probe starts the packaged machine service under its isolated offline environment, reads its authenticated discovery record, and polls `/api/fast_search` until required/ready/full semantic evidence appears.

### WHY

Standalone CLI polling created a fresh short-lived runtime for every attempt. On Windows the model loaded, but each process ended before background embeddings produced the encoder row, leaving one eligible symbol and zero vectors for the full 120-second probe.

### HOW

The implementation reuses Julie's existing JSON API contract and Python standard library HTTP client. It requires bearer auth from `service.json`, preserves semantic-backend/no-fallback checks, bounds discovery and search, records HTTP/transport diagnostics, and stops/reaps the owned service in `finally`. The self-test failed on the missing persistent-service/API contract before the change and now passes.

### IMPACT

Windows, macOS, and Linux native probes now exercise the actual long-lived runtime that owns background indexing. Lead will sync the new SHA to win-test, rebuild incrementally, and rerun the real packaged semantic probe.
