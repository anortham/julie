## Windows lifecycle consolidated into the archive verifier

### WHAT

Windows archive verification now performs two stdio initializations from distinct directories, service PID reuse, status, restart, old-PID exit, stop, restarted-PID exit, and discovery removal. The hanging inline PowerShell lifecycle step is removed.

### WHY

PowerShell pipeline capture blocked for more than two minutes during packaged initialize. The Python verifier already solved descendant-held pipe hangs with file-backed subprocess I/O, so maintaining a second capture implementation was both slower to debug and less reliable.

### HOW

The existing verifier `run` helper gained an optional cwd. Windows lifecycle reuses that helper plus the existing discovery-removal wait, and polls `tasklist` for both old and restarted service PIDs. The focused workflow contract failed before consolidation and now passes; the verifier regression test also passes.

### IMPACT

GitHub and local win-test now share one Windows package/lifecycle verifier. Lead can sync this commit and run the exact verifier against the already built NTFS archive without another hosted run.
