## Native qualification lifecycle proof corrected

### WHAT

The native workflow follow-up now validates initialization output and lifecycle invariants on macOS and Windows instead of merely invoking commands.

### WHY

Plan 4E requires proof that packaged binaries deliver routing instructions, reuse one service across sessions, restart to a new service, and leave no process behind. The first workflow version did not assert those outcomes.

### HOW

The runtime probe parses initialize JSON, requires nonempty instructions mentioning workspace routing, records the first service PID, confirms the second launch directory reuses it, verifies restart changes the PID and terminates the old process, then stops and checks cleanup. The exact contract test was extended through RED/GREEN. Repository search found no reusable cross-platform cached/offline semantic probe, so no speculative duplicate was added.

### IMPACT

The artifact-only workflow can now produce auditable native package and service-lifecycle evidence. Cached/offline native semantics remains a separate external evidence row after the workflow runs.
