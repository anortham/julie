## CLI JSON preserves request-engine readiness

### WHAT

`CliToolOutput` now carries the `RequestReadiness` returned by `RequestEngine`. The generic JSON command path converts that output into `ToolReply` with the real readiness instead of constructing `Auto` readiness.

### WHY

The native probe requested required semantics, but the CLI envelope always reported auto mode. That hid the executed policy and made strict qualification impossible.

### HOW

A focused transport test first failed because required/full readiness was absent. The minimal fix threads the existing readiness value through `CliToolOutput` and `into_tool_reply`. Lead review caught and corrected a consumed-value compile error by calculating the exit code before consuming the output.

### IMPACT

Generic CLI JSON now reports the policy and coverage the request engine actually used. The exact regression and binary type-check pass locally. A new native hosted run would still require separate owner authorization.
