## Cross-platform cached/offline semantic qualification probe ready

### WHAT

The native qualification workflow now invokes a small Python-stdlib probe against each extracted macOS and Windows archive. The probe prepares the pinned model into a disposable cache, verifies its SHA-256, blocks external HTTPS while preserving localhost, creates a scratch Git workspace, and requires a packaged semantic search to return the known symbol with `mode=required`, `status=ready`, and `coverage=full`.

### WHY

Plan 4E requires cached/offline semantic readiness on every advertised native target. Archive verification and service lifecycle checks alone do not prove the packaged native sidecar can use a warm model without network access.

### HOW

The script owns all profile, cache, workspace, and service state under runner temp and always stops the service. Its deterministic `--self-test` uses fake prepare output and the exact production readiness envelope. Lead review removed an invented compatibility field; the real-shape test failed first and then passed after correction.

### IMPACT

A single nonpublishing matrix run can now close package, lifecycle, Windows-lock, and cached/offline semantic evidence for macOS arm64, macOS Intel, and Windows x64.
