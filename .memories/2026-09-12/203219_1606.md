## Removed superseded workspace runtime lifecycle

### WHAT

- Deleted the obsolete `workspace_runtime` builder, manager, owner, scheduler, dirty queue, and shutdown modules.
- Reduced `workspace_runtime/mod.rs` to the active edit journal and source-edit exports.
- Marked the two historical lifecycle plans as superseded for runtime ownership.

### WHY

- Plan 3 now owns request lifetime through `RequestEngine` and `RuntimeFactory`; the old manager/lease/phase architecture had no callers.

### HOW

- Verified references for each removed API before deletion and retained edit journaling/recovery modules.
- Compiled the root crate after removal.

### IMPACT

- Removes unreachable lifecycle code without changing active edit/recovery behavior.
