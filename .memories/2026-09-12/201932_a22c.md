## Retirement barrier test timeout containment

**WHAT:** Added bounded waits and explicit spawned-task cleanup to the same-key retirement test.

**WHY:** The exact test hung for more than 60 seconds during lead and worker runs, leaving a blocked retirement task alive after an assertion path.

**HOW:** The test now bounds barrier entry, unrelated-key acquisition, retirement completion, and reacquisition. On any bound failure it releases the stored permit and aborts/joins remaining spawned tasks before panicking.

**IMPACT:** The test cannot leave the Tokio runtime waiting on a blocked spawned teardown future. The exact test still did not produce a final result before the worker run was interrupted, so the remaining lifecycle stall needs lead diagnosis.
