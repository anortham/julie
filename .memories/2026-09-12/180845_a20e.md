## WHAT
Replaced Julie's repeat-broad-test workflow with a fixed verification budget across AGENTS.md, CLAUDE.md, TESTING_GUIDE, the verification ledger template, the revival roadmap, and Plan2.
## WHY
Plan2 implementation was complete, but repeated Windows full-suite runs exposed unrelated failures one at a time and silently expanded the task for hours. Exact-SHA evidence rules also encouraged rerunning gates after documentation commits.
## HOW
Broad tests are now branch events after code freeze. The lead gets one initial broad run and one retry after exact in-scope fixes; a third needs an explicit owner decision. Unrelated, pre-existing, platform-only, and fixture-only failures become separate work. Unclear ownership gets at most15minutes or one exact diagnostic. Windows full is qualification, not the edit loop. Evidence-only descendant commits may reuse a pass when their diff cannot affect the command. Status must distinguish implementation complete from a pending gate.
## IMPACT
Future agents should use exact tests during implementation, stop broad-test loops after one retry, and avoid absorbing baseline cleanup into feature branches. Plan2 is recorded as implementation complete with Windows qualification paused. No Cargo suite is warranted for this documentation-only policy change.
