## Task 3: deleted primary swap, session attachment, deferred auto-index

### WHAT
- `src/handler.rs` 2770 -> 2224 lines (Task 1 start: 2991). Deleted `PrimarySwapRollback`, `switch_primary_workspace_with_root`, `activate_workspace_with_root`, the session attachment helpers, the session-lifecycle plumbing, and the deferred auto-index flag, gate, and in-flight slot.
- Deleted `src/registry/workspace_session_attachment.rs` and `src/registry/session.rs` (`SessionTracker`).
- `SessionWorkspaceState` keeps only startup hint, roots snapshot, primary binding, and the active set.
- `manage_workspace open` binds the target into the active set (`mark_workspace_active`) and indexes it when pending. It never swaps the handler's primary.
- `resolve_workspace_filter` marks a known ready workspace active; the `PrimarySwapInProgress` and `AutoActivationFailed` branches are gone (variants deleted in julie-core).
- `ToolContext::is_primary_workspace_swap_in_progress` deleted from julie-context, the fake context, and julie-tools.
- Dashboard: `DashboardState::new` no longer takes a `SessionTracker`; the session-phase panel, `active_sessions`, and per-workspace "current primaries" counts are gone from state, routes, and templates.

### WHY
The machine service creates one handler per `(root, index_root)` in `RuntimeFactory::acquire`, and that path already runs `initialize_workspace_with_force` and the startup catch-up. A handler never changes workspace, so the swap, attach, and defer machinery was code for states that cannot exist.

### HOW
- The registry upsert that `attach_workspace_once` did on bind now lives in one helper, `register_workspace_row`, called at the same sites.
- `initialize_workspace_with_force` stores the loaded workspace, binds the primary, and registers the row inline; no rollback capture.
- `on_initialized` for a roots-preferring startup resolves roots then runs the normal auto-index repair; `on_roots_list_changed` only marks roots dirty.
- Tests asserting the swap gap ("Primary workspace identity unavailable during swap"), attachment counts, or deferral were deleted; `open_lifecycle.rs` keeps the "open binds and indexes" cases.
