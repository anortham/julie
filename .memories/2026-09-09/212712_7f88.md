## Task 1: Service process and JSON API

Implemented the machine service skeleton in `src/service/`:
- `src/service/discovery.rs`: `ServiceRecord`, atomic `service.json` write with tempfile+rename and mode 0600 on Unix, read and remove helpers, 64-hex token generation.
- `src/service/status.rs`: `StatusLog`, `StatusDocument`, request/error ring buffers, process RSS reporting, idle duration tracking.
- `src/service/http.rs`: Axum router with `/status` and `/api/{tool}` endpoints, bearer/query token middleware, RequestEngine integration.
- `src/service/mod.rs`: `ServiceConfig`, `ServiceApp`, `run_service`, idle watch and graceful shutdown.
- `crates/julie-core/src/paths.rs`: `service_json(&self) -> PathBuf`.
- `Cargo.toml`: direct `reqwest` 0.13.3 dependency with `json` and `rustls`, and enabled `json` feature on `axum`.
- `src/cli.rs` and `src/main.rs`: `Command::Service(ServiceArgs)` wired into CLI and main dispatch.
- `src/tests/service/`: 8 comprehensive tests in `http_api.rs` all passing.
