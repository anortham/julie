## Phase 1 review fixes (machine-service branch)

### WHAT
Lead review of the six phase-1 tasks found four defects and fixed three in code:
- **Idle exit ignored MCP traffic.** Only `/api/*` called `StatusLog::begin/end`, so a service used only over `/mcp` exited after `JULIE_SERVICE_IDLE_SECS` mid-session and MCP calls never appeared on `/status`. Fixed with a `track_mcp_activity` middleware in `src/service/http.rs`; `default_mcp_headers` now also sets an `mcp-method` header from the body. Test: `mcp_traffic_counts_as_activity_for_idle_exit_and_the_status_log`.
- **Shim died when the service went away.** A failed POST returned an error and ended the stdio loop, so every stdio host lost the server on a service crash or `service stop`. `shim::forward` now takes `paths` and a spawn hook, reconnects once through `connect_or_start`, and retries the POST. Test: `shim_reconnects_when_the_service_goes_away_mid_session`.
- **`reqwest` pulled TLS + QUIC.** The plan said features `json` only; the worker added `rustls`, which added aws-lc-sys, cmake, quinn (367 lock lines). Dropped the feature; localhost HTTP needs no TLS.
- Deleted dead `cli_command_needs_workspace_startup_hint` and unused `RequestEngine::with_service_url`.

### Not fixed, reported to the user
- `src/service/` passes the 600-line budget only with `#[rustfmt::skip]` packing; `rustfmt` output is 736 lines. Policy call for the user.
- Ledger rows for the final dev gate cite commit `facb50d9`, which is not on the branch (rewritten); dev tier rerun on the fixed tree passed (29 buckets, 210 s).
