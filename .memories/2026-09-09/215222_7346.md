## Task 4: Service control and dashboard mount

Added service control verb handlers (status, stop, restart), POST /shutdown endpoint, merged dashboard router under /, updated manage_workspace dashboard to return the service URL, and deleted legacy standalone background dashboard spawn path.

- **WHAT**: Implemented Task 4 of Machine Service Phase 1 plan.
- **WHY**: Unifies dashboard serving with the single-port machine service and provides CLI service lifecycle control commands (`status`, `stop`, `restart`).
- **HOW**:
  - `src/service/http.rs`: Added `shutdown: CancellationToken` to `AppState`, added `POST /shutdown` route returning 202 `{"stopping":true}` with delayed cancel, and merged dashboard router before token middleware layer.
  - `src/service/mod.rs`: Plumbed shutdown token from `AppState` into graceful shutdown, and set `engine.service_url` after binding listener.
  - `src/service/client.rs`: Added `exit_code` mapping `VersionMismatch` to 3 and others to 1; exposed `from_record`.
  - `src/dashboard/mod.rs`: Added `dashboard_router(paths)` factory.
  - `src/dashboard/standalone.rs`: Deleted background server spawning, Mutex caches, and legacy handlers; replaced `serve_dashboard_forever` with `open_dashboard` connecting via `connect_or_start`.
  - `src/request_engine/dispatch.rs`: Added `service_url` to `RequestEngine`; returned tool reply with URL for `manage_workspace dashboard` when service URL is present.
  - `src/main.rs`: Handled `Command::Service` verbs (`Status`, `Stop`, `Restart`) and mapped `ConnectError::VersionMismatch` to exit code 3 with exact format.
- **IMPACT**: Standalone background dashboard spawn path is completely removed; all tests green.
